Format du match

Le PCF Open : toi et les 7 bots, en élimination directe. Quarts et demi-finales en 2 sets gagnants, finale en 3 sets gagnants, comme un Grand Chelem. Les têtes de série sont placées selon leur niveau.

Points par set

Le format officiel du PCF est le set de 11 points, avec 2 points d'écart. Le set de 7 points donne des matchs plus courts, mais laisse moins de place aux remontées.

Le format ne peut pas changer pendant un match ou un tournoi.

Installer PCF sur l'écran d'accueil

iPhone (Safari) :

  1. touche le bouton Partager (le carré avec une flèche) ;
  2. choisis « Sur l'écran d'accueil » ;
  3. touche « Ajouter ».

Android (Chrome) :

  1. touche le menu ⋮ en haut à droite ;
  2. choisis « Installer l'application » ou « Ajouter à l'écran d'accueil ».
